\# ☀️ Solar Savings Assessment



\## Personal Solar Assessment Tool by Mark Fitzpatrick



A free, interactive solar savings assessment tool designed to help homeowners, businesses, commercial operators and farming customers estimate their solar requirements, battery options and potential energy savings.



Built as a lightweight web application that can be hosted for free using GitHub Pages.



\---



\# 🚀 Overview



The Solar Savings Assessment helps potential customers understand:



✅ Recommended solar system size  

✅ Battery storage options  

✅ Estimated annual electricity savings  

✅ Estimated payback period  

✅ Long-term solar benefits  



The tool is designed as a lead-generation funnel for renewable energy consultations.

\- Electricity usage patterns

\- Equipment selection

\- Installation requirements



A detailed assessment should be completed before final recommendations.
